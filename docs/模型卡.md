# AML Evidence Graph 模型卡

## 用途与边界

本系统为交易级 AML 风险排序与人工调查辅助而设计。预测对象是单笔交易边的
`is_laundering` 标签（来自公开合成数据集 SAML-D）；输出是调查优先级概率，而不是
账户标签、案件结论、监管申报决定或自动拒绝决策。

账户风险、资金路径和 `investigation_candidate` 仅在交易评分后，从交易字段、模型
概率和规则证据聚合得到，不能回灌为监督标签或交易模型特征。LLM 不参与评分、校准、
阈值或案件结论；可在证据约束下起草 SAR / 可疑交易报告草稿供人工复核。

## 数据与切分

- 数据集：公开合成 **SAML-D**（约 950 万笔交易）；结论表述为合成基准实验，不外推真实业务效果。
- 训练：2022-10-07 至 2023-04-30。
- 验证：2023-05-01 至 2023-06-30；只用于模型选择、融合校准和阈值。
- 测试：2023-07-01 至 2023-08-23；冻结后一次性评估（1,558,821 行 / 1,813 正例，
  正例率 ≈ 0.116%）。
- 公开仓库、Demo、CI 和文档不含密钥与完整模型产物；本地 `artifacts/` 不入 Git。

所有 PIT 窗口和图邻居只使用事件时点之前的数据；同一时间戳交易不互相可见。测试标签不
进入图推理，验证/测试不做重采样。全量指标与复现命令见 [实验结果.md](实验结果.md)、
[环境配置.md](环境配置.md) 的全量复现清单。

## 候选模型

1. 审批规则基线（`configs/rules/default.yaml` v2026.2）。
2. Logistic Regression、CatBoost、LightGBM 与 XGBoost 表格候选；LightGBM 已通过
   双 seed、配对 Bootstrap、OOF、融合和服务门禁，现为主线表格组件；CatBoost 为历史对照。
3. 因果图统计 + CatBoost（对照 / ablation）。
4. 历史边邻居采样的图边分类（架构可选 GraphSAGE / GAT / RGCN / PNA）。同协议全量对比后
   **GAT 为主线图模型**，当前双组件融合为 `lightgbm + GAT`；见 RESULTS
   「Edge GNN architecture comparison」与「Main-line model choice」。
5. 训练期时间滚动 OOF 的逻辑回归融合器，以及只在验证集选择的概率校准器和告警阈值。

图模型报告账户重叠率、冷启动账户/交易比例、边数量、吞吐和 CPU/GPU 内存；未知账户
只映射到稳定哈希桶，不从未来节点拟合映射。

## 全量主线指标（公开合成 SAML-D）

主指标为 **PR-AUC**；ROC-AUC 在此极低正例率下仅作次要参考。完整表见
[实验结果.md](实验结果.md)。

| 模型 | 角色 | 测试 PR-AUC | 0.1% 预算 Precision / Recall | run_id |
|---|---|---:|---:|---|
| rules (v2026.2) | 基线 | 0.0015 | 0.0019 / 0.0017 | `20260725T103959Z-27c7d65545` |
| logistic | 表格 | 0.1966 | 0.2809 / 0.2416 | 同上 |
| **LightGBM FE v2** | **主线表格** | **0.9014** | **0.9403 / 0.8086** | `20260811T082808Z-6f164d7ad8` |
| CatBoost FE v2 | 历史表格对照 | 0.8754 | 0.8999 / 0.7739 | `20260727T101815Z-14ce85d76a` |
| XGBoost FE v2 | 表格对照 | 0.8969 | 0.9359 / 0.8047 | 同上 |
| **GAT + 时点新颖性** | **主线图** | **0.9714** | **0.9814 / 0.8439** | checkpoint `8c7bb6cf63ec` |
| **LightGBM FE v2 + 本机 GAT v1 replay** | **OOF 融合** | **0.9561** | **0.9827 / 0.8450** | `20260811T083954Z-048e8d1338` |

历史 v1 同协议边 GNN 架构对比：GAT 0.9483 / RGCN 0.9031 / GraphSAGE 0.8777 / PNA 0.7049；
另做多关系 RGCN（R=4，`artifacts/rgcn_rel`）消融测试 PR-AUC **0.8873**（未超过单关系
RGCN / GAT）。详见 [实验结果.md](实验结果.md) 的“Edge GNN”与负实验附录。

**必须同时披露的口径**：当前融合使用本机 GAT v1 replay，不含时点新颖性 checkpoint；其
PR-AUC `0.9561` 高于 LightGBM FE v2，但**不**优于主线 GAT + 时点新颖性 `0.9714`。
融合用于证明 expanding-time OOF stacking 与校准能力，不包装为性能冠军。

告警削减（相对规则、同召回）：LightGBM 在 50% 召回点削减约 **99.86%**；精确值由
`artifacts/table_lightgbm_fe_v2/metrics.json` 的 `alert_reduction_vs_rules` 生成。

`graph_stats_catboost` 与含该组件的三路融合另作历史对照，见 RESULTS；主线报告优先引用
LightGBM、GAT 与 `lightgbm + GAT` 双组件融合。当前融合不含 `graph_stats`。

LightGBM/XGBoost 使用相同 FE v2 输入和训练采样。LightGBM 相对 CatBoost 的测试 PR-AUC
配对点差为 `+0.02599`，95% CI `[+0.02084,+0.03196]`；双 seed 验证 PR-AUC 为
`0.89408/0.89531`。LightGBM 已生成 4,524,912 条 expanding-time OOF，并完成冻结融合、
训练期类别词表、模型持久化、SHAP/重要性解释和受控服务加载，替换链路已经闭环。

CatBoost FE v2 曾作为主线表格模型；现已被 LightGBM FE v2 替换。本节保留为历史特征工程
实验记录，GAT FE v2 仍未晋升。

- 指标唯一真值来源：`artifacts/table_baseline_fe_v2/metrics.json`。
- 运行状态时间来源：`artifacts/logs/fe_v2_pipeline_status.json`（仅状态/时间）。
- sidecar 流程：scripts/pipelines/run_fe_v2_pipeline_resumable.py。
- sidecar 指标（CatBoost）：
  - validation PR-AUC：**0.8660898669**
  - validation ROC-AUC：**0.9982223689**
  - test PR-AUC：**0.8754139061**
  - test ROC-AUC：**0.9984022445**
  - 相对历史 CatBoost v1 test PR-AUC 0.8092：**+0.0662**（四舍五入）
- Linux 权威产物的 FE v2 GAT / CatBoost+GAT 融合测试 PR-AUC 为
  **0.93887 / 0.95540**。
- `CatBoost FE v2 + 历史 GAT v1` 跨版本融合为 **0.95761**，相对历史 GAT
  差值 `+0.00928`，200 次配对 Bootstrap 95% CI 为 `[+0.00357, +0.01621]`。
- 第二 seed GAT 为 **0.92949**，显示图模型存在不可忽略的训练波动；跨版本融合
  因此继续作为 sidecar 候选，暂不覆盖主线。
- 工程 Pareto 仅用验证集选中 60 天历史窗口；唯一冻结测试 PR-AUC 为 **0.95206**，
  相对 30 天 GAT v1 点差 `+0.00373`，200 次配对 Bootstrap 95% CI
  `[-0.00147, +0.00915]`，不支持显著提升。它仍是 sidecar；全测试快照物化约
  29.2 分钟、RSS 峰值约 10.32 GiB。
- 60 天候选在任一端点新账户 / 低度非零切片 PR-AUC 仅 **0.7915 / 0.6070**，
  显著弱于两端点已见 / 高度切片的 **0.9863 / 0.9936**；不得只披露总体指标。
- 60 天固定配置的 leave-one-family-out 验证显示：移除节点统计、时间窗口行为、关系特征后
  PR-AUC 分别为 **0.20203 / 0.82913 / 0.86613**，低于完整配置的 **0.92423**；移除金额族

  不解释为金额无用，也不使用这些结果重新选择测试候选。
- 说明：smoke 路径仅用于工程链路验证，不得作为正式效果数字；该 sidecar 数值仍需结合
  过拟合风险、采样/切分差异做后续复核。

## 评价与晋升

统一报告 PR-AUC、概率输入的 ROC-AUC、KS、Brier、ECE、固定告警预算的
Precision/Recall、固定 FPR Recall、每发现一例所需告警数、**固定召回下相对规则基线的
告警削减率**、月度/模式/新账户切片、漂移和资源消耗。只有当验证期相对基线的收益、
告警预算表现、校准和资源均满足预先记录的准入规则时，图模型或融合模型才可晋升。

任何公开指标都必须链接到对应 run manifest、数据/特征/规则/模型/校准版本及复现命令，
并标注数据为公开合成 SAML-D。烟雾路径产物仅用于工程验证，不得回填本卡。

## 已知限制与人工控制

- **新账户切片样本量不足**：测试期 `sender_new` 有 345,067 行但仅 1 个正例，
  该切片的 PR-AUC 不具统计意义，只能作为覆盖性检查。
- **规则基线口径**：`configs/rules/default.yaml` v2026.2 的三条阈值规则在训练期
  分位数上定阈（验证/测试期未参与），测试期告警率约 8.79%、召回约 0.215。
  告警削减率必须相对该基线、在同召回点上报告。见 [规则基线.md](规则基线.md)。
- 合成标签与真实洗钱分布存在差异；不得把合成指标当作真实业务识别率。
- 主线报告优先引用表格 LightGBM、**GAT** 与 **`lightgbm + GAT` 融合**；GraphSAGE 融合与
  `graph_stats_catboost` 仅作对照。引用融合数字时须同时披露单独 GAT（更高）。
- 标签覆盖与案件关闭延迟可能造成概念漂移或选择偏差；按月和模式切片监控。
- 未知账户哈希桶存在碰撞风险；必须在冷启动切片中报告。
- 图路径和 SHAP 说明模型/历史证据，不构成因果或犯罪认定。
- 无证据、矛盾证据和工具失败的调查草稿必须标记不确定性并交由人工复核。
- 人工复核记录只用于审计；不会在线更新模型。
- Golden（`golden/cases_v1.json`）为用户授权 agent 裁定的项目回归集
  （`golden/adjudication_v1.json`）；当前模板路径评测为 **34** 案（原 30 + B5 对抗扩容）。
  不是独立第三方人工评审团，也不是生产合规标签。
- 算力附录（漂移 / 社区 / 无监督 / 序列 / 蒸馏 / 非线性融合 / 批式重放 / 多关系 RGCN）
  为 JD 对齐消融，**不改变**上表主线数字；见 RESULTS 附录。
