# 文档索引

本目录只保留长期维护的权威文档。阶段性计划、单轮实验记录和已被后续结论覆盖的过程稿已合并；
原文仍可通过 Git 历史追溯。公开数字以 [简历证据.md](简历证据.md) 为唯一门禁来源，完整上下文
以 [实验结果.md](实验结果.md) 和 [模型卡.md](模型卡.md) 为准。

当前公开版本为
[v1.0.0-resume](https://github.com/juhaoyang666-hash/aml_evidence_graph/releases/tag/v1.0.0-resume)：
P0/P1 求职工程项已闭环，Mock 发布烟雾和 GitHub CI 已通过。三个 README 的职责为：

- [仓库 README](../README.md)：面向招聘者的项目总览、结果、Demo 与安装入口；
- 本页：长期维护文档索引与口径治理；
- [Golden README](../golden/README.md)：生成、检索、盲法和 Agent 回归集合说明。

## 维护规则

- 新实验先写入 `artifacts/` 的聚合报告；只有影响当前结论时才更新对应权威文档。
- 不再为单个 seed、一次消融或阶段计划新建长期文档；追加到对应主题文档并记录日期、run_id 与边界。
- 指标变更必须同步检查 `实验结果.md`、`模型卡.md`、`简历证据.md`、根目录 README。
- 删除或合并文档前运行 Markdown 链接检查；Git 历史承担过程审计，不在 `docs/` 保留重复快照。
- 离线入口和回归测试分别遵循 [scripts 目录规则](../scripts/README.md) 与
  [tests 目录规则](../tests/README.md)，不再向两个根目录堆积单文件。
