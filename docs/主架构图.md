# AML Evidence Graph 主架构

> 边界：风险分数只由规则和冻结机器学习模型产生；LLM/Agent 只读证据包，
> 不参与特征、模型分数、融合、阈值或案件结论。

```mermaid
flowchart LR
    subgraph S1[1. 因果风险评分]
        D[公开合成 SAML-D<br/>固定时间外切分]
        PIT[Point-in-Time 特征<br/>窗口: t-window, t]
        HG[历史交易图<br/>只含预测时点前边]
        R[版本化规则]
        CB[LightGBM]
        GAT[GAT 边分类]
        OOF[训练期 expanding-time OOF 融合<br/>验证期校准与锁定阈值]
        SCORE[冻结交易风险分数]

        D --> PIT
        D --> HG
        PIT --> R
        PIT --> CB
        HG --> GAT
        CB --> OOF
        GAT --> OOF
        R --> SCORE
        OOF --> SCORE
    end

    subgraph S2[2. 后评分证据聚合]
        ACCOUNT[账户风险视图]
        PATH[资金路径]
        CASE[关联案件视图]
        PKG[RiskEvidencePackage<br/>特征快照 + 规则命中 + 有界子图]

        SCORE --> ACCOUNT
        SCORE --> PATH
        SCORE --> CASE
        ACCOUNT --> PKG
        PATH --> PKG
        CASE --> PKG
    end

    subgraph S3[3. 受控调查 Agent]
        T1[get_feature_snapshot]
        T2[get_bounded_subgraph]
        T3[search_typologies]
        CHECK[事实白名单校验<br/>无证据拒答]
        DRAFT[调查 / SAR 草稿<br/>不是案件结论]

        PKG --> T1
        PKG --> T2
        PKG --> T3
        T1 --> CHECK
        T2 --> CHECK
        T3 --> CHECK
        CHECK --> DRAFT
    end

    subgraph S4[4. 人工审批与审计]
        HITL[LangGraph interrupt<br/>approve / edit / reject]
        AUDIT[独立只追加审计事件<br/>不保存证据正文]
        FINAL[人工复核后输出]

        DRAFT --> HITL
        HITL --> AUDIT
        HITL --> FINAL
    end

    LLM[可选外部 LLM<br/>仅用于非事实性注释]
    BLOCK[禁止路径<br/>LLM 不得进入风险评分]
    LLM -. 最小化证据摘要 .-> CHECK
    LLM -.-> BLOCK
```

## 数据与控制边界

| 边界 | 保证 |
|---|---|
| 时间 | PIT 特征和图邻居严格只读事件时点之前的历史 |
| 模型选择 | OOF 拟合，验证期校准/锁阈，测试期只做冻结评估 |
| 聚合 | 账户、路径、案件是交易分数的后评分聚合，不回灌为监督标签 |
| Agent | 只调用三个参数受限的只读工具，输出须通过事实校验 |
| 决策 | 人工审批前不产生最终调查结论或监管申报决定 |
| LLM | 不参与风险分数、融合权重、阈值或案件结论 |

[大模型调查系统](大模型调查系统.md)。
