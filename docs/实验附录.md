# 算法消融与负实验附录

本附录集中记录不改变主线模型选择、但对模型诊断和面试复核有价值的算力实验。正式主线指标、
run_id 与置信区间以 [实验结果.md](实验结果.md) 为准。

统一边界：实验均基于公开合成 SAML-D；采样实验不能与全量结果直接比较；负结果同样保留，
不得只挑选有利指标。当前主线为 CatBoost、GAT 以及 `catboost + GAT` OOF 融合，其中 GAT
单模型仍是主线中最强排序器。

## 汇总结论

| 实验 | 测试结果 | 结论 | 产物 |
|---|---:|---|---|
| 高分子图 Louvain / 连通分量 | case-account coverage 1.0 | 适合调查聚合，不是团伙识别模型 | `artifacts/community_baseline` |
| Isolation Forest / Autoencoder | sampled PR-AUC 0.0009 / 0.0053 | 接近机会水平，不替代监督模型 | `artifacts/unsupervised_baseline` |
| 多关系 RGCN（R=4） | PR-AUC 0.8873 | 低于单关系 RGCN 0.9031 和 GAT 0.9483 | `artifacts/rgcn_rel` |
| Sender GRU 序列模型 | sampled PR-AUC 0.0103 | 短发送序列不足以替代 PIT + GNN | `artifacts/sequence_baseline` |
| GAT 分数作为 CatBoost 特征 | PR-AUC 0.9656 | 两阶段 scorer 有效，但不是纯表格蒸馏 | `artifacts/table_baseline_gat_distill` |
| 非线性 OOF 融合 | MLP 0.9073；HistGBDT 0.0410 | 均未超过逻辑回归融合 0.9177 | `artifacts/nonlinear_fusion` |

## 1. 高分账户子图社区基线

**命令**：`PYTHONPATH=src python scripts/run_community_baseline.py`

协议：从 GAT 调查视图按 `max_risk_score` 取前 2,000 个账户，在 2023-07-25 至
2023-08-23 窗口做一跳扩展，得到 12,764 个节点、12,089 条无向边和 65,344 笔交易；
比较 NetworkX 连通分量与加权 Louvain，并用 212 个 GAT 案件视图作对照。

| 方法 | 大小≥2的社区 | Mean purity | Random purity | Top 10% 社区正账户占比 | 案件账户覆盖 | Mean best Jaccard |
|---|---:|---:|---:|---:|---:|---:|
| Connected components | 721 | 0.053 | 0.075 | 52.5% | 1.00 | 0.055 |
| Louvain | 724 | 0.053 | 0.075 | 52.7% | 1.00 | 0.055 |

Louvain 仅切断 3 条社区间边，说明该投影本身已接近连通分量结构。平均 purity lift 低于 1，
不能声称社区发现改善了风险识别；可以陈述高风险账户具有集中性，且调查案件账户均被覆盖。
这是高分种子子图上的同构离线聚合，不是全图异构 GNN 或生产团伙检测。

## 2. 无监督异常检测

**命令**：`PYTHONPATH=src python scripts/run_unsupervised_baseline.py`

使用 76 个数值 PIT 特征；从训练期负样本顺序采样最多 400k 行拟合，测试期采样 400k 行
（468 个正例）。Isolation Forest 使用 200 棵树；浅层 Autoencoder 训练 8 epoch，异常分为
缩放后的重构误差。

| 模型 | PR-AUC | ROC-AUC | 0.1% Precision | 0.1% Recall |
|---|---:|---:|---:|---:|
| Isolation Forest | 0.0009 | 0.418 | 0.000 | 0.000 |
| Autoencoder | 0.0053 | 0.479 | 0.005 | 约 0 |
| 机会水平（正例率） | 约 0.0012 | 0.5 | — | — |

结论是该合成 PIT 空间中的洗钱模式不等同于一般密度异常。由于训练和测试均有采样上限，
只能作为异常检测负基线，不能替代全量 CatBoost/GAT 对比。

## 3. 关系感知消融

**配置**：`configs/models.rgcn_rel.yaml`；完整 RGCN 产物：`artifacts/rgcn_rel`。

关系定义：

| ID | 关系 |
|---:|---|
| 0 | domestic × same currency |
| 1 | domestic × currency conversion |
| 2 | cross-border × same currency |
| 3 | cross-border × currency conversion |

| 模型 | Test PR-AUC | Val PR-AUC | 0.1% P/R | run_id |
|---|---:|---:|---|---|
| GAT | 0.9483 | — | 0.974 / 0.838 | `20260726T023031Z-5ccb81baec` |
| RGCN single-rel | 0.9031 | — | 0.905 / 0.778 | `20260726T062636Z-ef6be55956` |
| RGCN R=4 | 0.8873 | 0.8412 | 0.881 / 0.757 | `20260726T135457Z-045b0b06ab` |

R=4 训练约 28.5 分钟，在第 7 epoch 早停，四卡 RTX 3090 fan-out 下单卡峰值约 1.1 GB。
离散关系路由没有超过单关系 RGCN 或 GAT，因此保持 GAT 主线。

已有分数的关系切片：

| 关系 | GAT PR-AUC | RGCN PR-AUC | 测试行 | 正例 |
|---:|---:|---:|---:|---:|
| 0 | 0.932 | 0.872 | 1,380,504 | 1,100 |
| 1 | 0.975 | 0.936 | 25,534 | 121 |
| 2 | 1.000* | 1.000* | 770 | 7 |
| 3 | 0.973 | 0.957 | 152,013 | 585 |

\* 关系 2 只有 7 个正例，指标不稳定。另一个 CPU Edge MLP 对照中，加入 relation
embedding 后 PR-AUC 从 0.0379 降至 0.0363，同样没有收益。

## 4. Sender 序列 GRU

**命令**：`PYTHONPATH=src python scripts/run_sequence_baseline.py`

取发送账户交易时点前最后 K=32 个 outgoing event，单步特征为 `log1p(amount)`、
`log1p(delta_hours)`、payment type、cross-border 和 currency conversion；负样本哈希下采样到
每个 split 约 200k 行。

| Train/Test rows | Val PR-AUC | Test PR-AUC | Test ROC-AUC | 0.1% Precision |
|---|---:|---:|---:|---:|
| 206,170 / 201,813 | 0.011 | 0.010 | 0.514 | 0.035 |

这是 CPU、采样、仅发送侧短序列的负实验，说明该输入不足以取代 PIT 窗口聚合与 GNN；
不代表所有时序模型在 AML 上无效。

## 5. GAT 分数进入 CatBoost

**命令**：`PYTHONPATH=src python scripts/run_gat_distill_catboost.py`

训练期使用 `artifacts/graph_oof_gat` 的 expanding-time OOF 分数；验证和测试使用冻结完整 GAT
分数。CatBoost 输入为排除 `graph_*` 的 PIT 特征加 `gat_oof`，负样本策略与表格主线相同。

| 模型 | Test PR-AUC |
|---|---:|
| 纯 CatBoost 主线 | 0.8092 |
| GAT alone | 0.9483 |
| CatBoost + GAT score feature | 0.9656 |

该结果证明图分数与表格残差信息可以互补，但它是依赖 GAT 推理的两阶段 scorer，不是
“CatBoost 学会了图结构”，也不是可脱离 GAT 部署的纯表格蒸馏。

## 6. 非线性 OOF 融合

**命令**：`PYTHONPATH=src python scripts/run_nonlinear_fusion.py`

在 4,524,912 行 CatBoost + GAT 训练期 OOF 分数上比较逻辑回归、HistGradientBoosting 和
MLP `(16, 8)`；校准器和 0.5% 告警阈值仅在验证期拟合，测试期只评估。

| Head | Test PR-AUC | 0.1% P | 0.1% R |
|---|---:|---:|---:|
| Logistic（复现） | 0.9177 | 0.934 | 0.803 |
| MLP | 0.9073 | 0.912 | 0.784 |
| HistGBDT | 0.0410 | 0.178 | 0.153 |
| 正式逻辑融合产物 | 0.9175 | 0.936 | 0.805 |
| GAT alone | 0.9483 | 0.974 | 0.838 |

非线性 head 未改善融合，HistGBDT 在默认设置和极度不平衡下崩溃。继续保留逻辑回归融合，
同时披露它仍低于 GAT 单模型。
