## 完成结果（Linux 权威产物）

| 模型 | 测试 PR-AUC | 角色 |
|---|---:|---|
| CatBoost FE v2 | 0.87541 | 主线表格（相对 v1 CatBoost `0.8092`：`+0.0662`） |
| GAT FE v2 | 0.93887 | sidecar 图（**低于** v1 GAT `0.94833`） |
| CatBoost FE v2 + GAT FE v2 | 0.95540 | sidecar 融合 |
| CatBoost FE v2 + 历史 GAT v1 | 0.95761 | 跨版本 sidecar |

判定摘要：

1. FE v2 GAT **未**超过 v1 GAT `0.9483`。
2. FE v2 同版本融合超过 v1 `catboost+GAT` `0.9175`，也超过 FE v2 GAT 单模型。
3. 跨版本融合在 Linux 历史 checkpoint 上显著高于历史 GAT；Windows 本地重训对照未显著优于重训 GAT；第二 seed GAT `0.92949` 显示波动——故继续 sidecar。

## 跨版本融合对照

Linux 保存的历史 v1 GAT checkpoint、3 折 OOF 和逐交易分数允许执行严格同样本融合。
`CatBoost FE v2 + 历史 GAT v1` 的测试 PR-AUC 为 `0.95761`，高于历史 GAT v1 的
`0.94833`；200 次同交易分层配对 Bootstrap 点差为 `+0.00928`，95% CI
`[+0.00357, +0.01621]`。在 0.1% 告警预算下二者找到正例数为 `1536 / 1519`。

Windows 没有同一个历史 checkpoint，使用相同配置重训后的 GAT v1 PR-AUC 为 `0.95218`，
跨版本融合为 `0.95048`。配对点差 `-0.00171`，95% CI `[-0.00901, 0.00522]`；0.1%
预算融合少找到 19 个正例，0.5% / 1% 预算分别多找到 12 / 9 个。融合校准更好，但校准改善
不能解释成排序改善。

因此 Linux 结果支持把跨版本融合作为候选，跨机器/seed 证据则表明结论对 checkpoint 波动
敏感。它保持 sidecar，不覆盖 v1 GAT 主线，也不得把 Linux 历史产物与 Windows 重训描述为
逐字节复现。

产物：`artifacts/fusion_catboost_fe_v2_gat_v1`、
`artifacts/fusion_test_catboost_fe_v2_gat_v1`、
`artifacts/fusion_test_catboost_fe_v2_gat_v1_bootstrap`；Windows 对照后缀为
`*_local_replay`。目录包含逐交易分数，受 `.gitignore` 保护。
