# 面试自答要点（AML Evidence Graph）

面向头部公司**风控 / 反欺诈 / 图算法**实习面试。数字以 [RESULTS.md](RESULTS.md) 为准。  
配套简历段落：[RESUME_BLURB.md](RESUME_BLURB.md)。

## 1. 一分钟项目介绍

公开合成 SAML-D（~950 万笔、~0.1% 正例）上的**交易边二分类**：固定时间外切分，PIT 表格特征，历史图邻居采样的边 GNN，训练期 OOF 融合 + 验证期校准阈值，测试只评一次。  
主线：**CatBoost 0.809 / GAT 0.948 / CatBoost+GAT 融合 0.918**；相对规则 @R50 告警削减 ~99.9%。  
LLM 只写调查措辞，不碰分数。

## 2. 高频追问

### 为什么不用 ROC-AUC 当主指标？

正例约千分之一，ROC 容易虚高。主指标用 **PR-AUC**，并报 **固定告警预算**下的 Precision/Recall，以及**同召回相对规则的告警量**——更接近业务「能抓多少、要打多少警报」。

### 什么叫 PIT？如何防泄漏？

Point-in-time：每笔交易特征只聚合 **[t−window, t)** 的历史；同秒批次先全部评分再入历史。图侧当前日边只从**过去日期**采样邻居；训练期外账户进哈希桶，测试标签不进消息传递。OOF 是 expanding-time，融合只看训练期 OOF，校准/阈值只看验证期。

### 为什么主线图是 GAT 不是 GraphSAGE / RGCN？

同协议（同 PIT、同切分、同 hidden/层数/fanout/epoch）对比：GAT 0.948 > RGCN 0.903 > GraphSAGE 0.878 > PNA 0.705。选 GAT 是 bake-off 结果，不是调参作弊。

### 为什么还报融合？融合不是不如单 GAT 吗？

是的——**必须主动说**：融合 0.918 **低于** 单 GAT 0.948。  
报融合是因为系统形态是「表格行为 + 图结构」的 OOF 堆叠、校准与阈值策略；单 GAT 是峰值排序。两者都披露，避免只挑好看数字。相对 CatBoost（0.809）和旧 GraphSAGE 融合（0.897），融合仍有增益。

### graph_stats / 三路融合 PR-AUC≈0.999 算不算泄漏？为什么不进主线？

更像是**合成数据捷径**（账户对结构与标签高度绑定），不是典型的「把未来标签写进特征」。特征若是 history-only，协议上可算合法，但**不可外推、不可当模型能力**。主线只用 CatBoost+GAT（不含 graph_stats）。

### 规则基线怎么定的？告警削减怎么算？

三条阈值规则，阈值只在**训练期**分位数上定，验证/测试未参与定阈。削减 = 在相同召回目标下，模型告警数相对规则告警数的降幅（如 CatBoost @50% 召回：908 vs 649,036）。

### LLM 在项目里干什么？会不会乱写数字？

只生成分析性措辞和待查问题；出站字段最小化；返回做引用白名单 + 数值/实体正则拦截，失败则 `rejected_facts`。Golden 30：幻觉拦截率 1.0、无证据拒答率 1.0。评分链路完全不依赖 LLM。

### 合成数据有什么局限？

标签与真实洗钱分布不同；不能声称真实业务识别率。价值在于：**可复现的防泄漏协议、指标口径、工程闭环**，以及面试能讲清边界。

### CatBoost 为什么明显弱于 GAT？

表格特征主要刻画账户自身窗口行为；洗钱正例在合成数据里更依赖**账户对/图结构**。GAT 直接建模历史邻域，排序优势大。这是能力分工问题，不是「没调参」一句话能抹平——详见 [CATBOOST_GAP_DIAGNOSIS.md](CATBOOST_GAP_DIAGNOSIS.md)。

补充：试过训练期 OOF **hard-negative** 重训，测试 PR-AUC 从 0.809 **降到 0.455**，故主线仍用稳定哈希负采样；结构缺口交给 GAT 更划算。

### 有没有置信区间？0.02 的 PR-AUC 差靠谱吗？

主线训练默认 `bootstrap_iterations=0`。项目补做了测试集分层 bootstrap（200 次，见 RESULTS「Bootstrap CI」）：

- CatBoost PR-AUC ∈ **[0.791, 0.826]**
- GAT ∈ **[0.940, 0.955]**
- catboost+GAT ∈ **[0.907, 0.928]**

因此：融合相对 CatBoost 的提升、以及「融合仍低于单 GAT」，在该测试集上都是稳定的；原 GraphSAGE 融合点估计 0.897 低于 GAT 融合 CI 下界 0.907。

### 和信贷 / 广告反作弊岗怎么迁移讲？

共性：极稀正例、对抗与漂移、规则+模型、关联风险、可解释与人工复核。差异：本项目是 **AML 交易边 + 离线合成基准**，没有在线特征存储 / A/B / Hive 仓；若对方强调平台能力，诚实说离线可复现 pipeline，并指向批式特征说明（[BATCH_FEATURE_NOTE.md](BATCH_FEATURE_NOTE.md)）。
