# AML Evidence Graph 模型卡

## 用途与边界

本系统为交易级 AML 风险排序与人工调查辅助而设计。预测对象是单笔交易边的
`is_laundering` 标签（来自公开合成数据集 SAML-D）；输出是调查优先级概率，而不是
账户标签、案件结论、监管申报决定或自动拒绝决策。

账户风险、资金路径和 `investigation_candidate` 仅在交易评分后，从交易字段、模型
概率和规则证据聚合得到，不能回灌为监督标签或交易模型特征。LLM 不参与评分、校准、
阈值或案件结论；可在证据约束下起草 SAR / 可疑交易报告草稿供人工复核。

## 数据与切分

- 数据集：公开合成 **SAML-D**（约 950 万笔交易）；结论表述为合成基准实验，不外推真实业务效果。
- 训练：2022-10-07 至 2023-04-30。
- 验证：2023-05-01 至 2023-06-30；只用于模型选择、融合校准和阈值。
- 测试：2023-07-01 至 2023-08-23；冻结后一次性评估（1,558,821 行 / 1,813 正例，
  正例率 ≈ 0.116%）。
- 公开仓库、Demo、CI 和文档不含密钥与完整模型产物；本地 `artifacts/` 不入 Git。

所有 PIT 窗口和图邻居只使用事件时点之前的数据；同一时间戳交易不互相可见。测试标签不
进入图推理，验证/测试不做重采样。全量指标与复现命令见 [RESULTS.md](RESULTS.md)、
[FULL_RUN_AFTER_PIT.md](FULL_RUN_AFTER_PIT.md)。

## 候选模型

1. 审批规则基线（`configs/rules/default.yaml` v2026.2）。
2. Logistic Regression 与 CatBoost 表格基线。
3. 因果图统计 + CatBoost（对照 / ablation）。
4. 历史边邻居采样的图边分类（默认 GraphSAGE；GAT / RGCN / PNA 同协议全量对比已完成，
   见 RESULTS「Edge GNN architecture comparison」）。
5. 训练期时间滚动 OOF 融合器，以及只在验证集选择的概率校准器和告警阈值。

图模型报告账户重叠率、冷启动账户/交易比例、边数量、吞吐和 CPU/GPU 内存；未知账户
只映射到稳定哈希桶，不从未来节点拟合映射。

## 评价与晋升

统一报告 PR-AUC、概率输入的 ROC-AUC、KS、Brier、ECE、固定告警预算的
Precision/Recall、固定 FPR Recall、每发现一例所需告警数、**固定召回下相对规则基线的
告警削减率**、月度/模式/新账户切片、漂移和资源消耗。只有当验证期相对基线的收益、
告警预算表现、校准和资源均满足预先记录的准入规则时，图模型或融合模型才可晋升。

任何公开指标都必须链接到对应 run manifest、数据/特征/规则/模型/校准版本及复现命令，
并标注数据为公开合成 SAML-D。烟雾路径产物仅用于工程验证，不得回填本卡。

## 已知限制与人工控制

- **新账户切片样本量不足**：测试期 `sender_new` 有 345,067 行但仅 1 个正例，
  该切片的 PR-AUC 不具统计意义，只能作为覆盖性检查。
- **规则基线口径**：`configs/rules/default.yaml` v2026.2 的三条阈值规则在训练期
  分位数上定阈（验证/测试期未参与），测试期告警率约 8.79%、召回约 0.215。
  告警削减率必须相对该基线、在同召回点上报告。见 [RULE_BASELINE.md](RULE_BASELINE.md)。
- 合成标签与真实洗钱分布存在差异；不得把合成指标当作真实业务识别率。
- 主线报告优先引用表格 CatBoost 与 GraphSAGE；`graph_stats_catboost` 作为图统计对照基线。
- 标签覆盖与案件关闭延迟可能造成概念漂移或选择偏差；按月和模式切片监控。
- 未知账户哈希桶存在碰撞风险；必须在冷启动切片中报告。
- 图路径和 SHAP 说明模型/历史证据，不构成因果或犯罪认定。
- 无证据、矛盾证据和工具失败的调查草稿必须标记不确定性并交由人工复核。
- 人工复核记录只用于审计；不会在线更新模型。
- Golden（`golden/cases_v1.json`）为用户授权 agent 裁定的项目回归集
  （`golden/adjudication_v1.json`）；不是独立第三方人工评审团，也不是生产合规标签。
