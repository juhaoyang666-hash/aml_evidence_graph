# AML Evidence Graph 模型卡（预注册版本）

## 用途与边界

本系统为交易级 AML 风险排序与人工调查辅助而设计。预测对象是单笔交易边的
`is_laundering` 已确认案件标签；输出是调查优先级概率，而不是账户标签、案件结论、
监管申报决定或自动拒绝决策。

账户风险、资金路径和 `investigation_candidate` 仅在交易评分后，从 token 化交易、模型
概率和规则证据聚合得到，不能回灌为监督标签或交易模型特征。LLM 不参与评分、校准、
阈值或案件结论。

## 数据与切分

- 训练：2022-10-07 至 2023-04-30。
- 验证：2023-05-01 至 2023-06-30；只用于模型选择、融合校准和阈值。
- 测试：2023-07-01 至 2023-08-23；冻结后一次性评估。
- 数据仅在本机私有受控环境处理。账户在落盘前 HMAC token 化；公开仓库、Demo、CI 和
  文档不含真实交易、账户、模型产物或密钥。

所有 PIT 窗口和图邻居只使用事件时点之前的数据；同一时间戳交易不互相可见。测试标签不
进入图推理，验证/测试不做重采样。

## 候选模型

1. 审批规则基线。
2. Logistic Regression 与 CatBoost 表格基线。
3. 因果图统计 + CatBoost。
4. 历史边邻居采样的 GraphSAGE 交易边分类。
5. 训练期时间滚动 OOF 的逻辑回归融合器，以及只在验证集选择的概率校准器和告警阈值。

GraphSAGE 报告账户重叠率、冷启动账户/交易比例、边数量、吞吐和 CPU/GPU 内存；未知账户
只映射到稳定哈希桶，不从未来节点拟合映射。

## 评价与晋升

统一报告 PR-AUC、概率输入的 ROC-AUC、KS、Brier、ECE、固定告警预算的
Precision/Recall、固定 FPR Recall、每发现一例所需告警数、月度/模式/新账户切片、漂移和
资源消耗。只有当验证期相对基线的收益、告警预算表现、校准和资源均满足预先记录的准入
规则时，图模型或融合模型才可晋升。

当前尚未执行受控私有全量训练与最终测试，因此本模型卡不包含任何实际效果数字。任何
未来公开指标都必须链接到对应私有 run manifest、数据/特征/规则/模型/校准版本及复现命令。

## 已知限制与人工控制

- 标签覆盖与案件关闭延迟可能造成概念漂移或选择偏差；按月和模式切片监控。
- 未知账户哈希桶存在碰撞风险；必须在冷启动切片中报告。
- 图路径和 SHAP 说明模型/历史证据，不构成因果或犯罪认定。
- 无证据、矛盾证据和工具失败的调查草稿必须标记不确定性并交由人工复核。
- 人工复核记录只用于审计；不会在线更新模型。
