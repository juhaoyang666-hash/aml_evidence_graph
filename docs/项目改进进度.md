## 一、总体结论

当前已经形成可演示、可复现的 AML 风险排序与证据约束调查原型。投递前 P0 工作约完成
`90%`，P1 工作约完成 `80%`，P2 选做项尚未开始。

项目最完整的技术主线是：

1. 对约 950 万笔公开合成交易构建严格 Point-in-Time 特征和历史交易图。
2. 使用规则、LR、CatBoost 和 GAT 完成交易级风险边排序。
3. 采用固定时间外切分、PR-AUC、固定告警预算、Bootstrap、漂移和资源指标评估。
4. 将账户、资金路径和案件视图作为交易分数的后评分聚合，不构造账户监督标签。
5. 将 LLM/Agent 限制在证据包、白名单工具、事实校验和人工审批范围内，不参与风险打分。

当前不建议替换 v1 GAT 主排序器。虽然 Linux 历史 GAT + FE v2 CatBoost
跨版本融合显著提升，但第二 seed GAT 从 `0.94833` 波动到 `0.92949`，
且 Windows 本地重训对照中跨版本融合并未提升。因此 FE v2 和跨版本融合继续
作为 sidecar，等稳定性与新账户特征证据齐全后再评估晋升。

## 三、已经完成的落地工作

### 3.1 FE v2 与跨版本实验

FE v2 七步链已经完成，包括表格模型、GAT、两类 OOF、融合、冻结测试、200 次 Bootstrap
和调查视图。当前主要测试结果为：

| 模型 | 测试 PR-AUC | 当前角色 |
|---|---:|---|
| CatBoost FE v2 | 0.87541 | sidecar 表格模型 |
| GAT FE v2（Linux 权威产物） | 0.93887 | sidecar 图模型 |
| CatBoost FE v2 + GAT FE v2（Linux） | 0.95540 | sidecar 融合 |
| 历史 GAT v1（Linux） | 0.94833 | 主线图模型 |
| CatBoost FE v2 + 历史 GAT v1（Linux） | 0.95761 | 跨版本 sidecar 融合 |

Linux 权威环境后续找回了历史 v1 GAT 的完整 checkpoint、OOF 和逐交易分数，
并补做了 `CatBoost FE v2 + 历史 GAT v1`。该融合测试 PR-AUC 为
`0.95761`，高于历史 GAT 的 `0.94833`；200 次同样本配对 Bootstrap 差值为
`+0.00928`，95% 区间 `[+0.00357, +0.01621]`。该结果与下述 Windows 本地
重训版结果不同，说明结论对 checkpoint / 训练波动敏感；当前作为更强的
主线候选，仍保持 sidecar。

作为跨机器稳定性对照，Windows run 的 FE v2 GAT / 融合为 `0.90937 / 0.93193`；
GAT v1 本地重训 / 跨版本融合为 `0.95218 / 0.95048`。后者相对 GAT v1 本地重训
的 PR-AUC 点差为 `-0.00171`；200 次配对分层 Bootstrap 的
95% 区间为 `[-0.00901, 0.00522]`，不支持融合显著优于 GAT。0.1% 告警预算下 GAT v1
多发现 19 个正例；0.5% 和 1% 预算下融合分别多发现 12 和 9 个正例。

详细证据见：[GATv1与CatBoostFEv2融合实验.md](GATv1与CatBoostFEv2融合实验.md)、
[特征工程V2实验.md](特征工程V2实验.md)。

Windows 对照环境缺少历史 v1 GAT checkpoint 的逐交易分数，因此当时使用同配置
重新训练；Linux 补充实验则使用原历史产物。两组 run 不得混为逐字节复现。

- 检索 Golden 从 80 条扩展到 130 条，其中 107 条可回答、23 条无答案。
- 已比较 BM25、dense、hybrid 和 hybrid+rerank。
- 冻结 hybrid 的 Recall@3/MRR 为 `0.799/0.752`。
- 有来源新增切片的 Recall@3/MRR 为 `0.952/0.976`。
- 中文切片 Recall@3 为 `0.646`。
- 无答案误召回率为 `0.304`，相对旧 80 案的 `0.200` 退化。

已用 v2 作校准集、v3 作 case ID 隔离的冻结测试。校准后仍选中 `0.35`；v2
无答案误召回率为 `0.200`，v3 为 `0.500`。这证明单一余弦阈值未泛化，
当前不改默认阈值，不把 rerank 晋升为默认。

在该失败之后开发的二阶段 answerability gate，v2 五折 OOF 的 Recall@3 / 无答案误召回率
为 `0.700 / 0.067`；v3 回顾性诊断为 `0.905 / 0.000`。由于方案是在看到 v3 失败后形成，
该结果不能再称为独立冻结验证，且 Recall 有所下降；门控保持实验性，等待新盲审集合。

详细证据见：[检索评估.md](检索评估.md)。

### 3.3 受控 Agent、HITL 与审计

### 4.2 最终简历证据门禁（已关闭）

Linux 机器的 v1 CatBoost、GAT、主线融合与 FE v2 三路产物已通过 run_id、
输入/配置指纹、测试行数、正例数、时间范围、概率列和 Bootstrap 次数校验。
`docs/简历证据.md` 已生成，`public_ready=true`。门禁还发现 Linux runner 完成态为

权威产物同时显示 Linux FE v2 GAT / 融合测试 PR-AUC 为 `0.93887 / 0.95540`；
旧快照中的 `0.90937 / 0.93193` 属于另一台机器的 run，不应混为同一产物。

### 4.3 GAT 工程型消融（已关闭）

当前已有模型架构 bake-off、第二 seed 和工程参数 Pareto。固定 seed、只读 train/validation
的六个候选中，60 天窗口 validation PR-AUC 为 `0.92423`，高于 30 天基线的 `0.91788`；
按预注册规则选为唯一冻结测试候选。其 test PR-AUC 为 `0.95206`，相对 30 天 GAT
`0.94833` 点差 `+0.00373`；200 次配对 Bootstrap 95% CI
`[-0.00147, +0.00915]`，不支持显著提升。详细结果见
[GAT工程Pareto实验.md](GAT工程Pareto实验.md)。

最优配置的第二随机种子已完成：`0.92949`，相对首 seed `0.94833` 下降 `0.01884`，
必须披露波动。四组 leave-one-family-out 也已完成：移除金额、节点统计、关系和时间窗口行为
后的 validation PR-AUC 为 `0.93115 / 0.20203 / 0.86613 / 0.82913`，完整 60d 为
`0.92423`。节点统计最关键；移除金额后的单次提升只提示重叠或噪声，不能解释为金额无用。
所有工程配置和特征消融均只使用 train/validation，未用 test 选择
batch/fanout/window/feature family。

风险切片显示主要缺口在新账户和低度交易：任一端点新账户、低度非零 PR-AUC 为
`0.7915 / 0.6070`，而两端点已见、高度交易为 `0.9863 / 0.9936`。跨境和换汇均约
`0.9756`，不是当前首要弱点。

## 六、建议的下一步顺序

### 第一优先级：针对 GAT 已识别弱点做下一轮特征迭代

1. 时点新颖性和度数交互已完成预注册拆分、双 seed 消融和压力测试；详细证据见
   [新账户与低度特征实验.md](新账户与低度特征实验.md)。
2. 时点新颖性两 seed 的 PR-AUC 稳定，但低度切片仍有波动；保留为候选 sidecar。
3. 度数交互的高分按 SAML-D 合成生成器结构捷径处理，不据此解冻 test，也不作为可外推业务收益。
4. 用额外 seed 复核金额族的正向消融现象，避免把重叠或训练波动误判为稳定收益。
5. 保留 60 天窗口为 sidecar；没有新增跨生成机制证据前不替换 v1 GAT 主排序器。

### 第二优先级：解决检索拒答的跨版本泛化

1. 保持当前 `0.35` 为默认基线，不根据已经观察过的 v3 反向调阈值。
2. 固定现有二阶段门控、阈值和特征契约，不再基于 v3 修改。
3. 新增独立裁定者盲审集合，只评估一次 Recall@3、MRR 和无答案误召回率。

### 第三优先级：补生产边界证据

- 为审批幂等增加数据库 CAS 或共享互斥，并验证多 worker exactly-once 语义。
- 按目标岗位需要，再补外部 LLM 的事实、token、成本、延迟评测或集群 Spark 写入证据。

QLoRA、MCP 和 Multi-Agent 继续保持 P2，不应抢占上述闭环工作的优先级。

## 七、当前可用于面试的诚实口径

> 在约 950 万笔公开合成 AML 交易上构建严格 Point-in-Time 特征和历史交易图，以 GAT
> 完成交易边风险排序，并使用时间外测试、告警预算和 Bootstrap 报告不确定性；同时构建
> RiskEvidencePackage 约束的受控 LangGraph 调查链，通过白名单工具、事实校验、持久化
> checkpoint 和人工审批实现可恢复、可审计的调查辅助。LLM 不参与风险打分，账户、路径和
> 案件均由交易结果后评分聚合产生。

必须同时披露：数据为公开合成数据；当前没有真实线上流量；GAT v1 仍是已晋升的主排序器；
Linux 历史 checkpoint 上跨版本融合显著提升，但 Windows 本地重训对照未提升，且第二 seed
显示 GAT 存在波动，因此融合仍是 sidecar；本地 Agent 幂等与审计结果不是多 worker 或生产合规验收。
