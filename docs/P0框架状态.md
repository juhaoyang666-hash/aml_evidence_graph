# 求职改进 P0 框架状态

本页记录 `风控算法实习项目改进建议_2026.md` 中 P0 建议的代码落地状态。
框架可运行不等于正式指标已完成；只有扩容后的 Golden、完整性能报告和完成产物才能写入简历。

## 已落地

| 能力 | 实现 | 当前边界 |
|---|---|---|
| 混合 Typology 检索 | BM25 + 固定版本多语言 SentenceTransformer + gated RRF + lexical-overlap rerank | 仅 5 篇 starter 文档，不代表生产知识库 |
| 检索评测 | 80 条 Golden；Recall@1/3、MRR、nDCG@3、拒答误召回和标签切片 | 作者裁定集，尚无独立合规专家复核 |
| 只读调查工具 | PIT 特征快照、有界历史子图、Typology 检索 | 当前从冻结 EvidenceStore 读取，不接受 SQL/路径/URL |
| 工具路由 | 确定性、最多 4 次的结构化请求 | 尚未启用 LLM 自主路由 |
| HITL | LangGraph interrupt + approve/edit/reject + checkpoint + 受控 API | SQLite 跨进程恢复已测试；生产仍需共享 checkpoint 后端 |
| Agent Golden | 60 案：路由 12、工具边界 24、审核 12、恢复 12 | 项目内合成裁定，不是独立合规验收 |
| 审计 | checkpoint 外独立 SQLite 追加存储；事件 ID 幂等；工具/节点/复核元数据可重开查询 | 不落正文、特征值、图边或备注正文；生产仍需 WORM/集中存储与组织保留策略 |
| 简历证据 | 校验 metrics/manifest、score 行数/正例/时间/概率、run_id、指纹、Bootstrap，并自动比较 v1/v2 | 本机缺 v1 三路权威产物，继续 `public_ready=false` |
| API 压测 | 健康、草稿、冻结 CatBoost v1 分区评分、Agent 完整周期均已实测 | 本机结果不是生产 SLA；冻结评分不含 GAT/融合 |

## 可选环境

使用清华 PyPI 镜像按目标任务安装；不要一次安装所有重型能力：

```powershell
$env:PIP_INDEX_URL = "https://pypi.tuna.tsinghua.edu.cn/simple"

# SQLite 持久化 checkpoint，已在当前 aml-evidence 环境安装并完成重启恢复烟雾验证
& $PY -m pip install -e ".[llm,agent-persistence]"

# 语义检索（当前本机已安装；模型权重不会进入仓库）
& $PY -m pip install -e ".[retrieval]"

# 以下属于 P1，按目标 JD 选择
& $PY -m pip install -e ".[mlops]"
& $PY -m pip install -e ".[spark]"
```

`benchmark` 仅依赖 httpx，已包含在当前 LLM 环境中。当前额外安装的是
`langgraph-checkpoint-sqlite 3.1.0`、`sentence-transformers 5.6.1`、`mlflow 3.14.0`、
`pyspark 3.5.9` 与 OpenJDK `17.0.14`。当前 PyTorch 为 GPU 版
`2.5.1+cu121` 且 CUDA 可用；Spark 本地等价链已运行。也可使用
`scripts/install_career_extras.ps1 -Group <agent|retrieval|mlops|spark>` 通过清华镜像分组安装。

## 2026-07-28 本机轻量验收

- 当前全仓测试：107 passed、1 个显式 JVM Spark 测试默认跳过；`pip check` 无依赖冲突；
  `src/tests` 与本轮脚本 Ruff 通过。Spark 端到端验收由独立重放/等价命令完成。
- SQLite checkpoint：关闭连接、重新创建工作流后，同一 `thread_id` 审批恢复成功。
- Mock `/healthz`：100 请求、并发 5、错误率 0%，p95 13.60 ms。
- Mock 调查草稿接口：50 请求、并发 5、错误率 0%，p95 123.48 ms。
- 检索 Golden：80 案（65 可回答、15 拒答）；gated hybrid Recall@3 `0.785`、MRR
  `0.731`、无答案误召回率 `0.200`，BM25 分别为 `0.615/0.567/0.467`。见
  [检索评估.md](检索评估.md)。
- Agent Golden：60 案；通过率、工具选择准确率、参数合法率、事实一致率、恢复成功率均为
  `1.0`，本机 p50/p95 约 `18.4/111.5 ms`；确定性基线未调用外部 LLM，token/cost 覆盖为
  `0.0`。见 [Agent调查评估.md](Agent调查评估.md)。
- 受控 Agent API：50 个启动→查询→审批恢复完整周期、并发 5、错误率 `0%`，吞吐
  `49.73 cycle/s`，p50/p95/p99 为 `93.12/147.16/155.85 ms`；不是生产 SLA。
- 审批幂等 HTTP 探针：50 个案件周期、并发 5、每案 8 个并发同键审批，共 400 个 review
  请求；错误率 `0%`、350 次持久化回放，审计库恰好 50 条 review 与 50 条 finalize。周期
  p50/p95/p99 为 `526.97/668.67/849.61 ms`；仅证明单 API 进程，不代表分布式 exactly-once。
- 冻结评分 API：v1 CatBoost 对 `2023-07-01` 完整 PIT 日期分区串行请求 10 次，错误率
  `0%`，吞吐 `1.85 partition/s`，p50/p95/p99 为 `547.23/633.43/652.36 ms`；不含 GAT
  或融合，不能解释为单笔交易在线延迟。
- FE v2 七步已 complete，但按当前决策保持 sidecar，不替换 v1 主线；本机仍缺 v1 三项完整
  产物，因此唯一简历证据报告保持 `public_ready=false`。当前 FE v2 三路已通过测试行数
  `1,558,821`、正例 `1,813`、时间范围、概率列和指纹核验，融合 Bootstrap 为 200 次；
  生成器仍因缺少 v1/sidecar 三组配对而拒绝公开，不得绕过门禁。

压测产物位于 `artifacts/serving_benchmark_*_p0*`；聚合结果见
[服务性能基准.md](服务性能基准.md)，属于当前 Windows 本机观测，不是生产 SLA。
