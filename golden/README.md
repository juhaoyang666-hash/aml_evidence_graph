# Golden Mock Cases

本目录仅含**虚构**评测种子，用于调查草稿 / Typology 检索 / SAR 草稿的自动化回归。

| 约定 | 说明 |
|---|---|
| 数据性质 | 非 SAML-D 抽样、非真实案件、非正式 100 案 Golden Set |
| 用途 | CI / 本地 smoke；验证证据约束与事实校验路径 |
| 不可用途 | 对外宣称调查准确率、替代人工标注 Golden Set |
| 当前规模 | `mock_cases.json` 共 6 案，覆盖 5 类 Typology + 1 个低证据案 |

正式 ~100 案人工复核集就绪前，文档与简历中应写明：**仅有 Mock Golden，非正式评测集**。
